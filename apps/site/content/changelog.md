# Changelog

## Unreleased

### Added

- Add YouTube videos to Study Pills by pasting a video link.
- Product-focused social preview images and structured data for search engines.
- A music-only product film showing the interactive Study Pill sample.
- A changelog on the landing page, maintained in Markdown.

### Changed

- The website and search descriptions now position Noteesta as an open-source alternative to Turbo AI and Google NotebookLM.
- Link previews use the current product message instead of the original sisters illustration.
- The landing page now leads with self-hosting, GitHub, and local setup instructions.

## 2026-11-15

### Added

- An interactive photosynthesis sample with simulated uploads, material selection, source-linked chapters, visuals, practice, and a 3D chloroplast. No account is needed to explore it.

## 2026-11-14

### Added

- In-place rich-text note editing with formatting and highlighting.
- Autosave and version history, including previews and restoration of earlier notes.
- Formatting controls that adapt to smaller screens.

## 2026-11-12

### Added

- Bring your own key (BYOK) for OpenAI, Anthropic, Google Gemini, Hugging Face Inference Providers, DeepSeek, and Z.ai, alongside local Ollama generation.
- Personal provider keys in Settings, encrypted at rest and never returned in full.
- An account-wide default generation model with per-Pill model choices.

Ollama still supplies the embedding model for source search with every generation provider. See the [setup guide](https://github.com/pradeept/noteesta#local-setup) for configuration.

## 2026-11-08

### Added

- Email and password authentication, Google sign-in, and email verification.
- Private workspaces with account-scoped Study Pills, collections, and source files.
- Password recovery and rotating sessions. See the [authentication guide](https://github.com/pradeept/noteesta/blob/main/docs/authentication.md) for setup.
